실시간 참여 진행 준비

워드클라우드, 막대 투표, 오픈 응답을 순서대로 띄웁니다. 참여자는 QR만 찍으면 로그인 없이 바로 응답합니다.

진행 중이던 세션이 있습니다.
코드 의 응답을 그대로 이어서 띄웁니다.

1. 응답을 모을 곳

참여자 휴대폰과 진행 화면을 실시간으로 잇는 저장소입니다.

Firebase 주소 만드는 방법 (5분, 무료)
  1. console.firebase.google.com에서 진행자 구글 계정으로 프로젝트 추가 (애널리틱스는 꺼도 됩니다)
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기, 위치는 싱가포르(asia-southeast1), 잠금 모드로 시작
  3. 규칙 탭에 아래 내용을 붙여넣고 게시
{
  "rules": {
    "sessions": {
      "$code": {
        ".read": true,
        "meta":    { ".write": true },
        "people":  { "$cid": { ".write": true, ".validate": "newData.isNumber()" } },
        "words":   { ".write": true, "$id": { ".validate": "newData.isString() && newData.val().length <= 20" } },
        "votes":   { ".write": true, "$cid": { ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() < 10" } },
        "answers": { ".write": true, "$id": { ".validate": "newData.isString() && newData.val().length <= 200" } }
      }
    }
  }
}
  1. 데이터 탭 맨 위의 주소(https://…firebasedatabase.app)를 복사해 위 칸에 붙여넣기

2. 질문 내용

줄바꿈은 화면에도 그대로 반영됩니다. 진행 중에도 바꿀 수 있습니다.
